
# Hope MVP

A self-contained, clickable demo for the pitch deck’s core flow:

1. Compare two media frames.
2. Read shared context.
3. Join an invite-only, moderated discussion pod.
4. Review a source-verification ledger.

## Run it

Open `index.html` in a browser. No installation, account, backend, or network connection is required.

The news scenario and outlet summaries are intentionally illustrative. They demonstrate the interaction model without presenting live or verified reporting.
